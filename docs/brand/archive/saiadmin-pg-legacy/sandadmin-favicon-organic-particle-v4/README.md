# SandAdmin favicon - fuller organic particle S v4

This revision keeps the natural particle flow from v3 while increasing favicon prominence:

- S width increased moderately without returning to a solid ribbon;
- main particle density increased by roughly one quarter;
- both luminous heads extend slightly across the hexagon border;
- the inner negative spaces remain open and readable;
- cyan hexagon retained without a dark outline;
- transparent background.

The ICO contains 16, 32, 48, 60, 64, 128, and 256 px frames. This concept has not replaced the runtime favicon.
