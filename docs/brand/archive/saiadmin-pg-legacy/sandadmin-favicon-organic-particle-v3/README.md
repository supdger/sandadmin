# SandAdmin favicon - organic particle S v3

This revision replaces the typographic, equal-width S with a naturally flowing particle stream:

- tapered luminous heads at both ends;
- asymmetric bends and changing width;
- irregular particle positions, sizes, density, and opacity;
- interwoven cyan, gold, and violet particles;
- cyan hexagon retained without a dark outline;
- transparent background.

The ICO contains 16, 32, 48, 60, 64, 128, and 256 px frames. This concept has not replaced the runtime favicon.
