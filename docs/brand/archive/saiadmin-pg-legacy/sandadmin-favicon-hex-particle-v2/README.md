# SandAdmin favicon - particle hexagon v2

Favicon-specific mark with a transparent background:

- cyan hexagon with no dark outline and no face fill;
- dense micro-particle S instead of a solid ribbon;
- faint glow under the particles for recognition at 16–32 px;
- cyan, gold, and violet palette retained from the full logo.

The ICO contains 16, 32, 48, 60, 64, 128, and 256 px frames. This concept has not replaced the runtime favicon.
