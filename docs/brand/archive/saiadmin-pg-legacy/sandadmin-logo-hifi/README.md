# SandAdmin high-fidelity logo package

This package is derived directly from the supplied 1024x1024 reference PNG.

- Source SHA-256: `3bf36a3567156c3ff59d622f10cb1e82998ad1fc162308c985c85cf590fa8363`
- `sandadmin-logo-master.png` and `sandadmin-logo-1024.png` are byte-identical copies of the source.
- 512px and 170px PNG files use Lanczos downsampling.
- ICO contains 16px, 32px, 48px, and 60px frames.
- The SVG embeds the original PNG bytes; it is self-contained and visually identical to the source.
- The dark background, grid, glow, particles, colors, and composition are preserved.
