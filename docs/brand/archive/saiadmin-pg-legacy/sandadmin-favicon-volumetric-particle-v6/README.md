# SandAdmin favicon - prominent volumetric particle S v6

This revision improves S prominence without turning it into a solid ribbon:

- both particle heads extend beyond the hexagon by approximately one border width;
- a dense bright particle spine strengthens the S silhouette;
- simulated depth still controls particle size, brightness, opacity, and position;
- gold, violet, and cyan lanes rotate with the S cross-section;
- a very soft colored volume glow supports the particles without filling them;
- transparent background and cyan hexagon retained.

The ICO contains 16, 32, 48, 60, 64, 128, and 256 px frames. This concept has not replaced the runtime favicon.
