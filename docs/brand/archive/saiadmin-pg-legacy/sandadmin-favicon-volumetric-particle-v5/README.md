# SandAdmin favicon - volumetric particle S v5

This revision models the S as a rotating three-dimensional particle ribbon rather than a flat particle mask:

- particle size, brightness, opacity, and position vary with simulated depth;
- gold, violet, and cyan lanes rotate with the S cross-section;
- edge-on portions narrow while facing portions expand;
- the S is moderately thicker and denser than v4;
- both luminous heads extend slightly outside the hexagon;
- cyan hexagon retained without a dark outline;
- transparent background.

The ICO contains 16, 32, 48, 60, 64, 128, and 256 px frames. This concept has not replaced the runtime favicon.
