# SandAdmin favicon - hexagon concept v1

This is a favicon-specific simplification of the full SandAdmin mark. It is not a direct reduction of the detailed logo.

Design choices:

- transparent background;
- one bold cyan hexagon instead of the open cube planes;
- a continuous, high-fill S with a dark contrast edge;
- the existing cyan, gold, and violet technology palette;
- reduced detail and controlled glow for recognition at 16–60 px.

Files:

- `sandadmin-favicon-master.svg`: editable vector master;
- `sandadmin-favicon-master.png`: browser-rendered 512 px transparent master;
- `sandadmin-favicon.ico`: 16, 32, 48, 60, 64, 128, and 256 px frames;
- `sandadmin-favicon-{size}.png`: transparent PNG exports;
- `sandadmin-favicon-preview.png`: light/dark and small-size visual check.

This concept has not replaced the current runtime favicon. Replace it only after visual approval.
