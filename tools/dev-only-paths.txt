# 开发专用代码清单：只在开发构建存在，生产发布包整段剔除。
#
# 语法（路径相对仓库根，正斜杠）：
#   rm <路径>     发布包中删除该文件或目录；目录递归删除整个子树；
#               允许 *（单段通配）与 **（跨段通配，兼容零段目录），
#               如 web/src/**/*.test.ts 同时命中 src 直属与子目录测试文件
#   strip <路径>  该文件含哨兵块，打包时删除 SAND-DEV-BEGIN 到
#               SAND-DEV-END 之间的所有行（含标记行）；哨兵用该语言
#               的行注释写（PHP/TS/Vue script 用 //，模板用 <!-- -->，
#               env/CSS 用 #或 /* */），必须成对、不嵌套
#
# 规矩：
#   - 新增开发专用代码必须登记进本清单，否则 tools/check-dev-refs.php
#     门禁失败；含哨兵块的文件也必须用 strip 登记，哨兵块之外不得再
#     出现 dev 符号，门禁会按剔除后的内容再扫一遍。
#   - 表达式需要「生产默认 + 开发覆盖」两种写法时，用 let/可变变量先给
#     生产值，再在哨兵块里覆盖；不要写两份并存的声明。
#   - 本清单自身不进发布包。
